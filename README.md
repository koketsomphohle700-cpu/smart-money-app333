# 🔥 Advanced Forex SMC Scanner

A professional-grade web-based forex trading scanner integrating **Smart Money Concepts (SMC)** with advanced technical analysis.

## 🚀 Features

### 📊 Smart Money Concepts (SMC)
- **Order Blocks (OB)** - Detect institutional buy/sell zones
- **Change of Character (CHOCH)** - Identify trend reversals
- **Break of Structure (BOS)** - Spot supply/demand breaches
- **Liquidity Pools** - Find areas of accumulation/distribution

### 📈 Technical Analysis
- **ADX (Average Directional Index)** - Trend strength confirmation
- **RSI (Relative Strength Index)** - Overbought/Oversold levels
- **MACD** - Momentum and trend crossovers
- **Bollinger Bands** - Volatility analysis
- **ATR (Average True Range)** - Risk calculation
- **Support/Resistance** - Key price levels

### 💡 Trading Features
- **Smart Entry Points** - AI-generated optimal entry levels
- **Multiple Exit Targets** - TP1, TP2, TP3 levels
- **Dynamic Stop Loss** - ATR-based risk management
- **Risk/Reward Ratios** - Instant P/L projections
- **Confidence Scoring** - Trade setup quality assessment (0-100%)

### 📱 Dual Mode Trading
- **Scalping** - 1-5 minute timeframes
- **Swing Trading** - 1H+ timeframes

### 🔌 Broker Integration
- MetaTrader 4 (MT4)
- MetaTrader 5 (MT5)
- cTrader
- Live account connection & trade execution

### 📊 Chart Analysis
- Upload chart images for instant analysis
- Automatic candle data extraction
- Price level identification
- Visual chart annotations

## 🎯 How to Use

### 1. Chart Upload & Scan
- Select a currency pair (EURUSD, GBPUSD, etc.)
- Choose timeframe (1M to 1D)
- Upload a chart image
- Click "Scan Chart"

### 2. View Analysis
The scanner will generate:
- **Bias & Direction** - BULLISH/BEARISH
- **Confidence Score** - Trade quality (0-100%)
- **SMC Signals** - Order blocks, CHOCH, BOS, liquidity
- **Technical Confirmation** - ADX, RSI, MACD alignment
- **AI Prediction** - Why this setup was generated

### 3. Trade Entry/Exit
- **Entry Point** - Precise entry level
- **Stop Loss** - Risk level
- **TP1/TP2/TP3** - Profit targets with escalating RR ratios
- **Lot Size** - Trade position size
- **Risk %** - Account risk per trade

### 4. Execute Trade
- Connect your broker account
- Click "Execute Trade"
- Monitor active trades in real-time
- Track P&L and ROI
